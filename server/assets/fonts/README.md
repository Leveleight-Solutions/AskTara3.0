These fonts are embedded as subsets in client proposal PDFs. They are not loaded from an external service when a client opens a proposal.

- `NotoSans-Regular.ttf`: [Noto Fonts official repository](https://github.com/notofonts/noto-fonts/tree/main/hinted/ttf/NotoSans), SIL Open Font License in `OFL.txt`.
- `NotoSansJP.ttf`: [Google Fonts official Noto Sans JP package](https://github.com/google/fonts/tree/main/ofl/notosansjp), SIL Open Font License in `OFL-NotoSansJP.txt`.

Noto Sans provides the main text, with Noto Sans JP for Japanese and CJK characters. These fonts do not claim exhaustive coverage of every writing system. Client text remains Unicode in the web proposal.
